# 🧠 CereBloom – Mood & Wellness Intelligence Platform

> **Turning Emotions Into Insights**

CereBloom is an AI-powered wellness analytics web application that combines journaling, sentiment analysis, wellness data processing, and interactive dashboards to help users better understand emotional and behavioral patterns.

This project was developed as a portfolio application focused on:
- 🤖 AI-assisted analytics
- 📊 Data visualization
- 💻 Frontend development
- 🧠 Sentiment analysis
- 🎨 User-centered UI/UX design

# 🛠️ Tech Stack

Language: Python 3.11
UI framework: Streamlit
Database: SQLite (via the standard library sqlite3 module)
Charts: Plotly Express and Plotly Graph Objects
Sentiment analysis: TextBlob (polarity-based scoring)
PDF parsing: pdfplumber
Image OCR: pytesseract + Pillow

# ⚡ Development Approach

CereBloom was primarily built through prompt-driven development using : Replit AI

The application was developed by iteratively refining prompts to generate:
- UI components
- Dashboard layouts
- Analysis workflows
- Feature integrations
- User experience improvements

This workflow allowed rapid prototyping and experimentation while focusing on usability and functionality.

# 🎯 Project Goals

The goal of Cerebloom was to explore how AI and sentiment analysis could be combined with wellness tracking to create a more meaningful and interactive user experience.

The project focuses on:
- Emotional trend analysis
- Context-aware sentiment interpretation
- Wellness data processing
- Interactive reporting
- Clean and accessible UI/UX
